# Финальный отчёт по стажировке (месяц Python + Web)

## 1. Что было изучено за месяц

За месяц я прошёл все основные темы, необходимые для junior-разработчика:

- **Python:** переменные, типы данных, условия, циклы, функции, коллекции, исключения, файлы, JSON, ООП, импорты, виртуальное окружение, pip, requirements.txt.
- **Git:** клонирование, ветки, коммиты, пуш, пул, мерж, разрешение конфликтов.
- **Web / HTTP / REST:** протокол HTTP, методы, статус-коды, заголовки, параметры запроса, REST-архитектура, JSON.
- **PostgreSQL:** таблицы, строки, колонки, первичные и внешние ключи, SELECT, INSERT, UPDATE, DELETE, JOIN, индексы (базово).
- **Django / DRF:** создание проекта и приложений, модели, миграции, админка, сериализаторы, вьюсеты, роутеры, права доступа, валидация, тесты.
- **Docker:** образы, контейнеры, Dockerfile, docker-compose, переменные окружения.

## 2. Какие проекты были сделаны

1. **Консольный менеджер заметок** (неделя 1) – работа с JSON, CRUD.
2. **User API на FastAPI** (неделя 2) – CRUD пользователей с PostgreSQL.
3. **Django REST API для задач** (неделя 3) – базовая работа с DRF.
4. **Финальный проект: Team Tasks API** (неделя 4) – полноценный REST API с JWT-аутентификацией, правами доступа, бизнес-правилами, тестами (12 тестов), логированием и Docker Compose.

## 3. Какие темы остались непонятными

В целом все темы понятны на базовом уровне, но для уверенной работы не хватает практики. Особенно нужно углубиться в:

- **Django и FastAPI** – чтобы уверенно писать сложные проекты, разбираться в жизненном цикле запроса, кастомизировать сериализаторы и права, оптимизировать запросы.
- **Работа в сети (HTTP, REST, API)** – понимание тонкостей статус-кодов, правильное проектирование эндпоинтов, работа с внешними API.
- **Postman** – освоить коллекции, окружения, автоматизацию тестов, работу с переменными.
- **Docker** – научиться писать более сложные Dockerfile, оптимизировать образы, использовать многоэтапную сборку, работать с сетями.

## 4. Что получается уверенно

- Базовый Python (написание скриптов, работа с коллекциями, функциями, классами).
- Работа с Git (коммиты, ветки, пулл-реквесты).
- Создание моделей, сериализаторов, вьюсетов и маршрутов в Django/DRF.
- Миграции и админка.
- Написание простых тестов для API (pytest, Django TestCase).
- Базовые SQL-запросы (SELECT, INSERT, UPDATE, DELETE, JOIN).
- Основы Docker (сборка образов, запуск контейнеров, docker-compose).

## 5. Что нужно повторить

- Django и DRF – особенно работа с permissions, сложные валидации, вложенные сериализаторы, оптимизация запросов (select_related, prefetch_related).
- FastAPI – чтобы сравнивать с Django и понимать различия.
- Работа с сетью – практиковать создание REST API, интеграцию с внешними сервисами.
- Postman – освоить все возможности для тестирования и документирования API.
- Docker – изучить многоконтейнерные приложения, управление переменными окружения, томов.
